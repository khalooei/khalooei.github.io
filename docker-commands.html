Docker — Practical Commands

Daily workflow cheat sheet

Git commands Speech simulators Academy hub

Images & build

docker build -t myapp:latest .
docker images docker rmi myapp:latest
docker pull python:3.11-slim docker tag python:3.11-slim myrepo/python:3.11

Run containers

docker run -d --name api -p 8080:8080 myapp:latest
docker run --rm -it -v ${PWD}:/workspace -w /workspace python:3.11 bash
docker ps -a docker logs -f api docker exec -it api bash

Compose & cleanup

docker compose up -d --build docker compose logs -f docker compose down -v
docker system df docker system prune -af

GPU (NVIDIA)

docker run --gpus all -it pytorch/pytorch:latest bash nvidia-smi
