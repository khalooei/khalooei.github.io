01
The game we are playing

Classification = drawing a boundary

A classifier looks at a point x and answers “class +1 or class −1?”. Every classifier therefore splits the plane into two regions; the line between them is the decision boundary. Learning means choosing that boundary from training data, and the real test is how well it does on new data it has never seen. Throughout this lab, pink is class −1, cyan is class +1, solid dots are training points and hollow rings are held-out test points.

fScore function

Each model computes a score; its sign is the predicted class and the boundary is where it equals zero.

✓Train vs test accuracy

Training accuracy can be made perfect by memorising. Test accuracy measures generalisation.

⚖Under- vs overfitting

Too simple a model misses the pattern (high bias); too flexible a model chases the noise (high variance).

02
Maximum margin + kernels

Support vector machines and the kernel trick

Of all lines that separate the data, the SVM picks the one with the widest margin — the widest empty street between the classes. Only the points on the edge of the street, the support vectors, decide where it goes. The parameter C sets how expensive it is for a point to step into the street. And by swapping the dot product for a kernel K(x, z), the very same algorithm draws curved boundaries: it implicitly works in a higher-dimensional feature space without ever computing it.

⟷Soft-margin primal

Maximise the margin 2/‖w‖ while paying C for each unit of violation ξ.

αDual & support vectors

The solution depends only on kernels between points. Points with α > 0 are support vectors.

KKernels, simple → complex

Linear, polynomial, sigmoid and RBF (Gaussian). RBF corresponds to an infinite-dimensional feature space.

03
Twenty questions

Decision trees

A decision tree asks a sequence of yes/no questions such as “is x₁ ≤ 0.3?”. Each question cuts a region with a straight, axis-parallel line, so the final boundary is a staircase of rectangles. The CART algorithm grows the tree greedily: at every node it tries every possible threshold on every feature and keeps the one that makes the children purest. Trees are easy to read and need no feature scaling — but grown deep they memorise the training set.

GImpurity

How mixed a node is, with p the fraction of class +1. Zero for a pure node, highest at p = ½.

ΔInformation gain

Pick the split that lowers the size-weighted impurity of the children the most.

✂Stopping & pruning

Limit max depth or require a minimum number of samples per leaf, otherwise the tree splits until every leaf is pure.

04
The wisdom of crowds

Bagging and random forests

A single deep tree has low bias but very high variance: change a few points and it changes completely. Bagging trains many trees, each on a bootstrap sample (n draws with replacement), and averages their votes — the noise of individual trees cancels out. A random forest adds one more twist: each split may only consider a random subset of features, which makes the trees more different from each other and the average even better. Extra-Trees go further and pick thresholds at random.

ΣAveraging

The forest’s probability is the mean of the trees’ leaf probabilities (soft voting).

ρWhy decorrelation matters

Averaging T trees with variance σ² and correlation ρ leaves a floor of ρσ². Random features lower ρ.

◌Out-of-bag estimate

Each bootstrap leaves out ≈ 36.8 % of points. Scoring them with the trees that never saw them gives a free validation estimate.

05
Learning from mistakes

Boosting: AdaBoost and gradient boosting

Bagging trains strong models in parallel and averages them. Boosting does the opposite: it trains weak models (often one-split “stumps”) one after another, and each new model concentrates on what the previous ones got wrong. AdaBoost does this by re-weighting the points; gradient boosting fits each new tree to the gradient of the loss — the residual errors. XGBoost, LightGBM and CatBoost are refined versions of the second idea and still win many competitions on tabular data.

αAdaBoost vote

A learner with weighted error ε gets a vote α: accurate learners speak louder.

wRe-weighting

Misclassified points get heavier, correctly classified ones lighter, so the next learner focuses on the hard cases.

∇Gradient boosting

Each tree fits the negative gradient of the log-loss; a learning rate η shrinks every step.

06
Four more ways to think

k-NN, logistic regression, Gaussian Bayes and neural networks

Each of these classifiers embodies a different idea. k-NN remembers everything and asks the neighbours. Logistic regression fits a probability with a linear score — nonlinear only through the features you give it. Gaussian Bayes models how each class generates data and applies Bayes’ rule. A neural network learns its own features layer by layer.

The model is linear in its features. With degree 1 the boundary is a straight line; add x₁², x₁x₂, x₂² … and the same linear model draws circles, ellipses and beyond. Training runs live with gradient descent (Adam).

σ(wᵀφ(x) + b)

σSigmoid output

The score is squashed into a probability; the boundary is where p = ½.

LCross-entropy loss

Convex in w, minimised by gradient descent; λ adds L2 regularisation.

φFeature map

All monomials up to degree d: (d+1)(d+2)/2 − 1 features.

Training loss
Try it: On Circles, degree 1 is stuck near 50 %. Degree 2 nails it, because a circle is x₁² + x₂² = r². Push the degree to 8 on noisy data and watch wiggles appear; then raise λ to tame them.
Simulator 6.3

Gaussian generative classifiers

Fit one Gaussian per class (ellipses show 1σ and 2σ), then classify with Bayes’ rule. The assumption about the covariance decides the shape of the boundary.

p(x|y) p(y)

BBayes’ rule

Pick the class with the larger posterior; the boundary is where the log-ratio is zero.

∥Naive Bayes

Assume features are independent given the class: axis-aligned ellipses.

ΣLDA vs QDA

One shared covariance gives a straight line (LDA); one per class gives a conic (QDA).

Covariance model
Try it: Paint a tight cluster of cyan points in the middle of a wide pink cloud. QDA draws a closed ellipse around it; LDA, forced to share one covariance, can only draw a line.
