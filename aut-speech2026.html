Research project: from a speech task to a conference-style paper

Each team chooses one speech task and works on it like a real conference submission. Before running anything, describe your project with the four cards below — this is the structure every speech paper follows.

1 · Task

Define the speech task precisely

  • Input and output (e.g., 16 kHz audio → text, speaker label, timestamps).
  • Category: content, speaker, paralinguistic, generation, enhancement or understanding.
  • Real-world use case and the hard part (noise, accents, overlap, low resource).
  • One-sentence research question and hypothesis.
2 · Ingredients

List what you need

  • Datasets with licence, size, language and official train/dev/test splits.
  • Front-end: log-Mel, MFCC, or an SSL upstream (wav2vec 2.0, HuBERT, WavLM, Whisper encoder).
  • Model / downstream head and at least one published baseline.
  • Compute budget, augmentation (noise, reverb, speed) and toolkits.
3 · Evaluation

Decide how success is measured

  • The standard metric of the task and its official scoring script.
  • Baselines to beat and the exact test condition (clean, noisy, cross-domain).
  • Ablations that show which ingredient matters.
  • Uncertainty: several seeds, confidence intervals or significance tests.
4 · Code

Structure the code for reproducibility

  • One config file per experiment; no hard-coded paths.
  • Data manifests instead of committing audio.
  • Separate train and evaluate scripts; fixed seeds; logged results.
  • A README that reproduces the main table with one command.

Recommended repository structure

speech-project/
├── README.md            # task, main results table, one-command reproduction
├── configs/             # one YAML per experiment (data, model, training)
│   └── wavlm_base_ser.yaml
├── data/
│   └── manifests/       # train/dev/test .jsonl: path, duration, label — never raw audio in git
├── src/
│   ├── datasets.py      # loading, resampling to 16 kHz, augmentation
│   ├── frontend.py      # log-Mel / MFCC or SSL upstream (WavLM, HuBERT, Whisper encoder)
│   ├── models/          # downstream heads
│   ├── train.py
│   └── evaluate.py      # official metric (WER, EER, DER …) + confidence intervals
├── scripts/             # prepare_data.sh, run_baseline.sh, run_all.sh
├── results/             # metrics.json per run, logs, plots
└── paper/               # 4-page conference template + figures

  1. Week 8Topic and one-page task card (task, ingredients, evaluation).

  3. Week 12Main experiments and ablations; first results table.
